## Codebase Patterns

- **OnchainOS Integration**: The project uses OnchainOS CLI commands to interact with blockchain data. The CLI commands are wrapped in async functions in src/utils/onchainos.ts.
- **Smart Contract**: The ExChainLock smart contract is implemented in Solidity and uses OpenZeppelin libraries for security (ReentrancyGuard, SafeERC20).
- **Testing**: The project uses Vitest for TypeScript testing and Hardhat for Solidity testing.
- **CLI**: The CLI is implemented in src/agent/cli.ts and supports scan and lock commands.
